# Mastermind instructions

In each game, your goal is to identify a hidden code of four colors.

- Six colors are available in every game.
- A color may appear more than once in the hidden code.
- You have up to 10 attempts per game.
- If the code is not solved in 10 attempts, the session continues with the next game.
- Each session contains four games.

After every guess, you receive feedback:

- A **black marker** means one color is correct and in the correct position.
- A **white marker** means one color is correct but in the wrong position.
- The order of the feedback markers does not correspond to the positions in your guess.

You will complete four sessions. The next session becomes available 24 hours after you complete the current session. Always return using the same participant link.

Use the same device, browser, and browser profile for all four sessions. Do not clear your browser data during the study. If you need to switch devices or browsers, contact the researcher to restore access without losing your progress.
